# Android Driver App

Native Android application for drivers who execute the pharmacy visit plans generated by the Python planner.

## How to work with Gemini / Android Studio

1. Open the `android/` folder as a project in Android Studio.
2. Use the prompts inside `docs/phases/` one phase at a time.
3. Always tell Gemini: "Do not rewrite existing files unless necessary. Make the smallest possible changes."

## Recommended Stack
- Kotlin
- Jetpack Compose + Material 3
- Hilt
- Room
- Navigation Compose
- Retrofit
- WorkManager
- CameraX (Phase 2)
