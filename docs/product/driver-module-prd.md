# Driver Module – Product Requirements Document

## Overview
This module adds a native Android application for **drivers / visitors** who execute the daily pharmacy visit routes generated by the Python planner (`plan_routes.py`).

The goal is to give every driver a clean, offline-first, one-handed experience to see their ordered daily route, navigate, mark visits as done, and report issues.

## Target User
- Field visitor / driver in Iran
- Works 5 days/week, ~9-hour days
- Often has unstable mobile data
- Needs large fonts, big buttons, minimal typing

## Core Value
"Open the app in the morning → see today’s ordered stops → start navigating → mark done → next stop."

## Key Features (Prioritized)

### Phase 1 – MVP (Must Have)
- Login with phone number + OTP (or simple PIN for internal use)
- Today’s Route screen (ordered list of stops)
- Stop detail (name, address, phone, time window, service minutes)
- One-tap navigation (Google Maps / Neshan / Waze)
- Mark stop as Completed / Failed / Skipped with reason
- Offline-first: full day plan downloaded and usable without internet
- Sync status when online

### Phase 2
- Photo proof of visit
- Signature capture (optional)
- Real-time ETA & traffic awareness
- Push notifications for route changes
- Simple chat / call manager button

### Phase 3
- Daily summary & performance stats
- Widget for next stop
- Dark mode + large text mode
- Multi-language (Persian first)

## Non-Goals (for now)
- Full CRM or order taking
- Live tracking of driver location for managers (can be added later)
- Complex inventory management

## Success Metrics
- Driver can start the day in under 20 seconds
- >90% of visits marked on the same day
- Offline usage works reliably
